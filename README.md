# MealFlow

Kişisel keto yemek planı uygulaması: günlük makrolar, reçeteler, ürün/marka/tedarikçi listeleri, stok, alışveriş listesi, maliyet (TL) ve kilo takibi.

- Adres: https://arbluy.github.io/mealflow/
- Veriler yalnızca telefonda (tarayıcı deposu) saklanır; bu repoda veri yoktur. Yedek: Ayarlar → Yedek al / Yedekten yükle.
- Fotoğraftan besin değeri/barkod okuma, Ayarlar'a girilen kişisel Anthropic API anahtarıyla çalışır; anahtar yalnızca cihazda tutulur.
- iPhone: Safari'de aç → Paylaş → Ana Ekrana Ekle.
